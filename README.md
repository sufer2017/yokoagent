# YokoAgent

YokoAgent 是一个部署在 Vercel 上的广告投放代理管理平台，包含两种角色：

- 代理：使用公司级账号密码登录，只能查看和编辑自己绑定的 `产品 + 渠道 + 代理商` T-1 投放数据
- 管理员：使用固定账号密码登录，管理代理账号、考核指标、站内告警和填报看板

## 技术栈

- Next.js 16 App Router
- React 19
- Ant Design 6
- @ant-design/charts
- Supabase 作为数据库
- JWT Cookie 作为轻量认证

## 本地启动

1. 安装依赖

```bash
npm install
```

2. 配置环境变量

复制 `.env.example` 到 `.env.local`，并填入：

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `JWT_SECRET`

管理员默认登录凭证：

- 用户名：`admin`
- 密码：`yzy19990704@`

如需覆盖，可额外设置：

- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`

3. 初始化数据库

将 [supabase/schema.sql](/Users/huanghaolong/yokoagent/supabase/schema.sql) 中的 SQL 执行到 Supabase 项目中。

如果本机暂时没有 Supabase 环境变量，应用会自动使用根目录下的 `.yokoagent-local-db.json` 作为本地持久化演示库；该文件已加入 `.gitignore`，只用于链路验收。

4. 启动开发服务器

```bash
npm run dev
```

## 功能说明

- 登录页支持“代理 / 管理员”角色切换
- 代理端支持按日期、体裁逐行填报 T-1 数据，CPA 由系统按 `消耗 / 激活数` 自动计算
- 代理端自动绑定产品、渠道和代理商，代理不可切换归属
- 管理员端首个 tab 为 `数据看板`：展示最近 21 天投放数据、8 张趋势小图、明细表和考核红线
- `填报看板` 只展示填报过程：已填 / 未填、首条填报时间、最后修改时间、填报行数、是否超时、近 21 天逾期情况
- 管理员端支持产品、公司级代理账号、渠道和考核指标历史管理
- 系统保存或导入数据后自动计算消耗/激活日环比、CPA/次留/7留日环比、周同比、考核偏离和站内告警
- `站内告警` 按消耗 / 激活 / CPA / 次留 / 7留拆分填列值、基准值和偏离百分比
- `考核指标`、`账号与渠道` 支持下载 CSV 模板和上传 CSV 批量导入
- 管理员端“账号与渠道”支持初始化 / 清空全链路演示数据，演示数据会真实写入 Supabase
- `数据看板` 支持下载 T-1 历史数据模板并上传 CSV，用于上线前导入真实预热数据

## 上线前一次性工作清单

1. 在 `账号与渠道` 点击 `清空演示数据`。
2. 录入真实渠道和代理公司账号密码。
3. 在 `考核指标` 录入每个在投代理的生效记录。
4. 导入或录入最近 21 天真实历史预热数据，确保日环比 / 周同比有基线。
5. 用 1-2 个真实代理账号做权限验收：不能读写其他代理数据。
6. 管理员检查数据看板、填报看板、未填代理、站内告警和指标管理均可正常使用。

## 部署

仓库推送到 GitHub `main` 分支后，可由 Vercel 自动构建部署。部署前请在 Vercel 项目里配置与本地一致的 Supabase 和 JWT 环境变量。

> 当前第一阶段不接飞书 API，不做飞书同步和群机器人 webhook。后续飞书多维表格只作为下游数据承接，飞书内部提醒交给 Aime 和多维表格自动化。
