# YokoAgent 操作手册

访问地址：`https://yokoagent.com`

适用对象：管理员、外部代理公司账号使用者。

YokoAgent 用于管理广告投放代理的 T-1 数据填报、考核指标、数据看板、填报进度和站内告警。系统分为管理员后台和代理工作台两类入口，代理账号只可查看和填报自己绑定的产品、渠道和代理商数据。

## 1. 登录

打开网站后，先选择登录身份。

- 管理员：选择 `管理员`，输入管理员账号和密码，进入管理后台。
- 代理：选择 `代理`，输入代理登录账号和密码，进入代理工作台。

登录后右上角可点击 `退出` 结束当前会话。

## 2. 正式启用初始化指南

正式启用前，管理员先完成演示数据清理和真实业务配置。所有操作均在网页完成，数据会直接写入线上数据库。

### 2.1 清理演示数据

如果系统中已有演示产品、演示渠道、演示代理账号、演示填报数据和演示告警，按以下顺序删除：

1. 进入 `账号与渠道 -> 代理账号`，先删除所有演示代理账号。
2. 删除代理账号后，该代理账号关联的填报数据、告警数据会同步清理。
3. 进入 `考核指标`，检查是否仍有演示考核记录；如有残留，逐条删除。
4. 进入 `账号与渠道 -> 产品`，删除不再需要的演示产品。
5. 进入 `账号与渠道 -> 渠道`，删除不再需要的演示渠道。

说明：

- 建议先删代理账号，再删考核指标、产品和渠道。
- `默认产品` 可以保留，不影响正式使用。
- 如正式业务会继续使用某个演示渠道或产品名称，可以直接编辑改名，不必删除后重建。

### 2.2 配置正式产品、渠道和代理账号

完成演示数据清理后，按以下顺序录入正式配置：

1. 进入 `账号与渠道 -> 产品`，新增正式产品。
2. 进入 `账号与渠道 -> 渠道`，新增正式渠道。
3. 进入 `账号与渠道 -> 代理账号`，新增正式代理账号，并绑定正确的产品、渠道和代理商。
4. 为每个代理账号设置登录账号和密码。
5. 如需飞书通知，填写该代理对应的飞书 webhook。
6. 确认账号状态为启用。

### 2.3 配置正式考核指标

正式代理账号创建完成后，进入 `考核指标` 配置考核红线：

1. 按 `产品 + 渠道 + 代理商 + 体裁` 新增考核记录。
2. 填写是否在投、生效日期、考核 CPA、考核次留、考核 7留和激活量级上限。
3. 同一代理商有多个体裁时，每个体裁单独建一条记录。
4. 考核值调整时，新增一条更晚生效日期的记录，不需要覆盖历史记录。

### 2.4 验证正式链路

正式启用前建议完成一次端到端验证：

1. 管理员确认 `账号与渠道` 中产品、渠道、代理账号均为正式配置。
2. 管理员确认 `考核指标` 中每个在投代理和体裁都有考核记录。
3. 使用一个正式代理账号登录代理工作台。
4. 在 `T-1数据填报` 提交一条测试填报。
5. 回到管理员后台，检查 `数据看板`、`填报看板`、`站内告警` 是否能看到对应数据。
6. 验证通过后，再通知代理正式开始每日填报。

## 3. 管理员后台

管理员后台包含 5 个菜单：`数据看板`、`填报看板`、`站内告警`、`考核指标`、`账号与渠道`。

### 3.1 账号与渠道

入口：`账号与渠道`

用途：维护产品、渠道、代理账号、登录密码、飞书 webhook 和账号启停状态。每个代理账号绑定唯一的 `产品 + 渠道 + 代理商`，代理登录后不能切换归属。

页面包含三个 Tab：

- `代理账号`：查看和维护代理账号名单。
- `渠道`：维护可用渠道。
- `产品`：维护可用产品。

代理账号表主要字段：

- 产品
- 渠道
- 代理商
- 登录账号
- 密码
- 飞书 webhook
- 账号状态

常用操作：

1. 点击 `新增代理账号`，选择产品、渠道，填写代理商名称、登录账号、飞书 webhook、密码和账号状态。
2. 新建账号时系统会预生成 10 位密码，管理员可以直接使用，也可以手动改写。
3. 点击代理账号行内的 `编辑`，可修改基础信息；`重置密码（可空）` 留空时不改变原密码，填写时会更新登录密码。
4. 点击 `删除` 会物理删除该代理账号，并同步删除该账号相关的填报、告警和考核记录。
5. 点击 `下载模板 CSV` 获取批量导入模板。
6. 点击 `上传 CSV 批量添加`，可批量新增或更新产品、渠道和代理账号。
7. 在 `渠道` Tab 点击 `新增渠道` 维护渠道名称。
8. 在 `产品` Tab 点击 `新增产品` 维护产品名称和启停状态。

CSV 导入建议字段：

- 产品
- 渠道
- 渠道状态
- 代理商名称
- 登录账号
- 密码
- 账号状态
- 飞书 webhook

说明：

- 新建代理账号必须填写密码。
- 更新已有代理账号时，CSV 中密码为空则保留原密码；填写密码则重置为新密码。
- 管理员可在代理账号名单中直接查看已记录的明文密码。
- 停用产品、渠道或代理账号后，相关对象不会出现在新增和筛选场景中。

### 3.2 考核指标

入口：`考核指标`

用途：维护每个代理在不同体裁下的在投状态和考核红线。填报数据、数据看板和告警都会按这里的记录匹配考核值。

考核指标表主要字段：

- 产品
- 渠道
- 代理商
- 体裁
- 是否在投
- 考核生效日期
- 考核 CPA
- 考核次留
- 考核 7留
- 激活量级上限

单条录入：

1. 点击 `新增考核记录`。
2. 依次选择产品、渠道、代理商。
3. 填写体裁、是否在投、考核生效日期。
4. 按需填写 CPA、次留、7留和激活量级上限。
5. 保存后记录立即进入考核匹配逻辑。

选择规则：

- 可以先选产品和渠道缩小代理商范围。
- 选择代理商后，系统会校验代理商是否属于所选产品和渠道。
- 产品、渠道、代理商三者不匹配时，系统会拒绝保存。

匹配规则：

- 系统按 `产品 + 渠道 + 代理商 + 体裁 + 数据日期` 匹配考核记录。
- 当多条记录满足条件时，使用 `考核生效日期 <= 数据日期` 的最新一条。
- 没有匹配考核记录时，相关考核偏离不会触发。

批量导入：

1. 点击 `下载模板 CSV`。
2. 按模板填写产品、渠道、代理商、体裁、是否在投、生效日期和考核值。
3. 点击 `上传 CSV 批量添加`。
4. 导入后检查错误提示；存在错误时按行号修正后重新上传。

### 3.3 数据看板

入口：`数据看板`

用途：查看投放数据趋势、KPI 卡片、异常状态和明细表。

顶部筛选项：

- 日期范围
- 产品
- 渠道
- 体裁
- 代理商
- 指标范围

核心区域：

- KPI 卡片：总消耗、总激活、CPA、次留、7留、填报进度。
- 趋势图：按时间查看消耗、激活、CPA、留存和异常变化。
- 数据明细：逐行查看填列值、考核值、日环比、周同比、偏离百分比和红线状态。

常用操作：

1. 先选择日期范围，再选择产品、渠道、体裁和代理商。
2. 用指标范围筛选定位高消耗、高 CPA、低留存等样本。
3. 在明细表中查看具体日期、代理商、体裁和异常类型。
4. 从站内告警点击 `查看数据看板` 跳转时，系统会自动带入对应产品、渠道、代理商、体裁，并将日期范围带到 T-8 至 T-1。

### 3.4 填报看板

入口：`填报看板`

用途：查看代理是否按时完成 T-1 数据填报。该页面聚焦填报过程，不用于查看投放数值表现。

核心指标：

- 应填代理天数
- 已填代理天数
- 准时已填
- 逾期已填
- 逾期未填
- 填报完成率

明细字段：

- 日期
- 产品
- 渠道
- 代理
- 填报状态
- 截止时间
- 首条填报时间
- 最后修改时间
- 填报行数
- 填写人

状态口径：

- 截止时间为北京时间 `数据日期 + 1 天 12:00`。
- 当某代理在某数据日期至少有 1 行填报记录，视为已填。
- 未填且超过截止时间，视为逾期未填。
- 已填但首条填报晚于截止时间，视为逾期已填。

常用操作：

1. 选择日期范围查看近期填报情况。
2. 按产品、渠道、代理、状态、填写人筛选。
3. 查看逾期排行榜，定位需要跟进的代理。
4. 查看明细表，确认具体日期和首次填报时间。

### 3.5 站内告警

入口：`站内告警`

用途：查看投放异常、生成今日日报重点、处理告警跟进状态。

页面结构：

- 导航筛选：处理状态，包含 `全部`、`已处理`、`未处理`。
- 今日日报重点：按严重程度展示需要优先关注的单条问题。
- 告警明细：按日期范围查看所有结构化告警项。

今日日报重点：

- 每条重点对应一个具体异常问题。
- 右侧提供 `查看数据看板` 和 `标记处理 / 撤销处理`。
- `查看数据看板` 会带入对应产品、渠道、代理商、体裁和 T-8 至 T-1 日期范围。
- `标记处理` 只处理当前这一条问题。
- `撤销处理` 只撤销当前这一条问题。
- 处理状态为 `全部` 时，点击按钮后当前条目留在原位，只切换按钮文案。
- 处理状态为 `已处理` 或 `未处理` 时，点击按钮后当前条目会从当前队列平滑移出，并可在另一个状态队列中找到。

告警明细：

- 可选择日期范围。
- 明细会拆成结构化字段：日期、产品、渠道、代理商、飞书 webhook、告警指标、告警类型、填列值、基准值、偏离百分比。
- 告警指标包括消耗、激活、CPA、次留、7留。
- 告警类型包括日环比偏离、周同比偏离、考核值偏离。

常用操作：

1. 在处理状态中选择 `未处理`，查看当前待跟进问题。
2. 点击单条重点的 `查看数据看板`，进入对应数据范围核查趋势和明细。
3. 跟进完成后点击 `标记处理`。
4. 如需恢复为待处理，切到 `已处理` 后点击 `撤销处理`。
5. 使用复制或下载功能导出今日日报重点 Markdown，供后续沟通使用。

## 4. 代理工作台

代理登录后只能访问自己绑定的产品、渠道和代理商数据。代理端包含 4 个 Tab：`T-1数据填报`、`数据看板`、`填报逾期情况`、`告警信息`。

### 4.1 T-1数据填报

入口：`T-1数据填报`

用途：代理按日期和体裁填写 T-1 投放数据。

填报步骤：

1. 选择数据日期，默认使用北京时间 T-1。
2. 查看页面顶部自动带出的产品、渠道和代理商。
3. 点击 `新增体裁行`。
4. 填写体裁、消耗、激活数、CTR、CVR、CPM、次留、7留。
5. 点击 `提交` 保存。

说明：

- 产品、渠道和代理商由账号自动绑定，代理不能修改。
- CPA 由系统按 `消耗 / 激活数` 自动计算。
- 同一日期可以按不同体裁填多行。
- 提交后系统会重算站内告警。

### 4.2 数据看板

入口：`数据看板`

用途：代理查看自己公司的投放数据、趋势和异常状态。

说明：

- 页面结构与管理员数据看板一致。
- 数据范围固定为当前代理账号绑定的产品、渠道和代理商。
- 代理不能查看其他代理商的数据。

常用操作：

1. 选择日期范围。
2. 按体裁或指标范围筛选。
3. 查看 KPI 卡片、趋势图和明细表。
4. 根据红线状态定位异常日期和体裁。

### 4.3 填报逾期情况

入口：`填报逾期情况`

用途：代理查看自己近期是否按时完成填报。

重点查看：

- 近 7 天填报状态。
- 是否存在逾期未填或逾期已填。
- 首条填报时间和截止时间。

### 4.4 告警信息

入口：`告警信息`

用途：代理查看自己公司的异常指标。

重点查看：

- 异常发生日期。
- 体裁。
- 告警指标。
- 告警类型。
- 填列值、基准值和偏离百分比。

说明：

- 代理端告警只保留轻量查看能力。
- 代理端不提供今日日报重点、一键导航和处理状态管理。

## 5. 日常运营流程

推荐按以下顺序维护系统：

1. 在 `账号与渠道` 维护产品、渠道和代理账号。
2. 在 `考核指标` 维护代理商、体裁和考核红线。
3. 代理每日在 `T-1数据填报` 提交前一日数据。
4. 管理员在 `填报看板` 检查是否有逾期未填。
5. 管理员在 `数据看板` 查看趋势和明细。
6. 管理员在 `站内告警` 跟进异常，处理完成后标记状态。

## 6. 权限与安全

- 管理员可查看全部产品、渠道、代理商、填报数据、考核指标和告警。
- 管理员可查看代理账号名单中的明文密码。
- 代理只能访问自己绑定的产品、渠道和代理商。
- 代理无法修改账号归属、考核指标、渠道、产品和其他代理的数据。
- 需要停用代理时，在 `账号与渠道` 将账号状态改为停用。

## 7. 常见问题

**代理忘记密码怎么办？**

管理员进入 `账号与渠道`，在代理账号行点击 `编辑`，填写 `重置密码（可空）` 并保存。保存后将新密码同步给代理。

**代理看不到其他公司数据是否正常？**

正常。代理账号只能读取和填报自己绑定的产品、渠道和代理商数据。

**为什么 CPA 不需要手动填写？**

CPA 由系统按 `消耗 / 激活数` 自动计算，避免填报口径不一致。

**为什么有些日环比、周同比或考核偏离为空？**

可能是没有历史基线、基线分母为 0，或没有匹配到考核指标。系统不会在缺少可靠基线时强行判定异常。

**为什么站内告警点击查看数据看板后筛选项会自动变化？**

这是为了直接进入对应异常的上下文。系统会带入当前异常所属的产品、渠道、代理商、体裁和 T-8 至 T-1 日期范围。

**标记处理后还能撤销吗？**

可以。管理员在 `站内告警` 的处理状态中选择 `已处理`，找到对应问题后点击 `撤销处理`。

**CSV 导入失败怎么办？**

先看弹窗中的行号和错误原因，常见问题包括必填字段为空、状态值不合法、账号与产品渠道不匹配、日期格式不正确。修正 CSV 后重新上传即可。
